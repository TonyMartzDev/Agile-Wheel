# AgileWheel 🎯

An interactive agile development platform that transforms how software teams collaborate, track progress, and deliver exceptional results.

## 🚀 Features

- **Interactive Agile Wheel**: Visual sprint cycle management with intuitive click-through stages
- **Real-Time Collaboration**: Keep your entire team synchronized with live updates
- **Progress Tracking**: Monitor velocity, burndown charts, and team performance
- **Modern UI**: Beautiful, responsive design built with React and TailwindCSS
- **Seamless Integration**: Works with your existing development tools

## 🛠️ Tech Stack

- **Frontend**: React 19 + Vite
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Build Tool**: Vite

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
